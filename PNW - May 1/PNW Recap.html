A regulated utility doesn't sell electricity, exactly. It sells the right to earn a return on the assets it builds to keep the desert cool.

The model · Rate base

A dollar enters. A fraction returns — by permission.

APS recovers prudently incurred costs plus an authorized return on its rate base — set by the Arizona Corporation Commission. Build more grid, earn more return. The capex isn't excess. It's fuel.

The bet · $10.35B capex

Build the grid the data center wants.

The 2025–2028 capex program is funded through operating cash, debt issuance, and equity — including $795M in equity infusions to APS in 2024 and an $850M ATM program available at year-end. Capex is not a leak. It is the rate base.

The weight · Capital structure

Build the grid on someone else's balance sheet.

Capital-intensive utilities don't run lean. They run leveraged — and APS is no exception. The bet is that rate-base growth keeps interest coverage where the rating agencies want it.
